## How to use
- `master-funnels.json` — loaded directly by simulator for node probabilities
- `business-archetypes-*.json` — 25 complete micro-step funnels with real probabilities
- Individual files — detailed reference with sources for every data point
- Every entry has: `metric`, `value`, `unit`, `source`, `year`
- Server loads all JSON files automatically and matches by keyword (top 5 datasets, 12KB context)
