## 19. Behavioral Patterns — Key Gaps & Notes

**Confirmed but no official public data:**
- % of users who use bookmarks feature specifically (X does not publish)
- Average number of bookmarks per user (not disclosed)
- % of bookmarks ever revisited (not disclosed)
- Thread completion rates by tweet count (3, 5, 10, 20) — no official A/B study published
- Exact "retweet without reading" rate (Twitter ran internal experiment in 2020 but did not publish exact %)
- "Unroll" tool usage (ThreadReaderApp, UnrollNow) — no MAU/DAU published

**Key behavioral insight — the 3-tier user model:**
- **Lurkers (~49%):** Read-only, post <5 tweets/month, visit weekly or less, 15 median followers
- **Passive engagers (~25–30%):** Like and RT but rarely create — consume news, follow trends
- **Creators/power users (~10–25%):** Generate 80–97% of all content, daily users, 159+ median followers

**Critical for product thinking:**
- The vast majority of users (75%) come to consume, not create
- 94% of news discovery on X happens via timeline scroll — not search, not trends
- Engagement funnel is extremely leaky: impression → click < 2% for most accounts
- Thread format outperforms single tweets by 54% on engagement but most users never finish them
- Screenshot sharing is massive (multiple tools built for it) — represents significant off-platform amplification that X cannot monetize
