## Regole Multi-Source (come gestiamo fonti multiple)

1. **2 fonti concordi** → media (McKinsey 70% + CB Insights 65% = 67.5%)
2. **2 fonti discordanti** → usa la piu' specifica per il contesto
3. **Mai nascondere una fonte** — entrambe visibili nella card del nodo
4. **Formato card**: "prob 67% — McKinsey 2024 (70%) | CB Insights 2024 (65%)"
