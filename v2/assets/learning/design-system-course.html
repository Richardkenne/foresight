Layer 01

Design Tokens

Tokens are the DNA of your UI. Named variables that store every design decision: colors, spacing, typography, shadows, radius, animation timing. Nothing in your UI should use a raw value. I token sono il DNA della tua UI. Variabili con nome che memorizzano ogni decisione di design: colori, spaziatura, tipografia, ombre, radius, tempi di animazione. Nulla nella UI deve usare un valore grezzo.

Why tokens existPerche' esistono i token

Imagine you hardcode #3b82f6 in 47 places. Now the designer says "make it darker." You must find and change all 47. Miss one? Inconsistency. With tokens: change --accent in ONE place. All 47 update instantly.Immagina di scrivere #3b82f6 in 47 posti. Il designer dice "rendilo piu' scuro." Devi trovare e cambiare tutti e 47. Ne dimentichi uno? Incoerenza. Con i token: cambi --accent in UN posto. Tutti e 47 si aggiornano.

5 States in CSS 
.btn {
  background: var(--surface);
  border: 1px solid var(--border);
  color: var(--text-muted);
  transition: all 0.15s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 1. DEFAULT: resting state (defined above) */

/* 2. HOVER: "you can click me" */
.btn:hover {
  background: var(--surface-2);
  border-color: var(--accent);
  color: var(--text);
  transform: translateY(-1px);  /* subtle lift */
}

/* 3. ACTIVE: "I'm being pressed" */
.btn:active {
  transform: scale(0.97);        /* press feedback */
  box-shadow: none;
}

/* 4. FOCUS: "keyboard is here" (accessibility!) */
.btn:focus-visible {
  box-shadow: 0 0 0 3px rgba(59,130,246,0.25);
  border-color: var(--accent);
  outline: none;
}

/* 5. DISABLED: "can't use this now" */
.btn:disabled {
  opacity: 0.4;
  cursor: not-allowed;
  pointer-events: none;
}
*
Why :focus-visible instead of :focus? :focus shows the ring on mouse click too (ugly). :focus-visible only shows it for keyboard navigation (Tab key). Best of both worlds.Perche' :focus-visible e non :focus? :focus mostra il ring anche al click del mouse (brutto). :focus-visible lo mostra solo per navigazione da tastiera (Tab).
