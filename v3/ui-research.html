Design Benchmarks (north star)

Linear NORTH STAR

Warm grays + LCH colors + Inter Display + minimal

Il gold standard. Grigi caldi (non blu-grigi). Colore SOLO per significato. Bordi appena visibili. Inter Display per heading. "Structure should be felt not seen."

Palette warm-gray + Inter Display + colore funzionale = la nostra direzione

Palantir Foundry Enterprise

Dark navy + data-dense + Blueprint design system

Enterprise ma elegante. Info density senza clutter. Colore solo funzionale (rosso=alert, verde=healthy, blu=selected). Pannelli multipli nella stessa vista.

Principio: colore funzionale, mai decorativo. Info density tramite spacing preciso.

Raycast NORTH STAR

Compact mode + keyboard-first + native feel

Search-first. Dark translucent. Keyboard shortcuts visibili in contesto. Compact mode: solo contenuto, zero chrome. Ogni pixel intenzionale.

Compact mode philosophy + keyboard shortcuts in context + content-first
