## Verdetto

**NON ESISTE** un tool open-source o consumer che faccia: "scrivi uno scenario in linguaggio naturale → vedi una simulazione visuale flowchart da inizio a fine con probabilita' reali da dati consulting".

Il competitor diretto piu' vicino e' **Machinations.io** (flussi animati, Monte Carlo, browser) ma e' pensato per game economy, non scenari di vita reale.

---

## Tier S — Design-first (qualita' Figma/Notion)

### 1. Pigment — pigment.com — UX 10/10
- **Tipo:** Web, enterprise FP&A scenario planning
- **Prezzo:** Enterprise (on-request)
- **UI:** Minimalista, typography Inter, palette carbon + cyan + burnt orange, animazioni fluide
- **Cosa fa:** Dashboards multi-dimensionali, modelli di scenario con propagazione real-time, what-if con tornado/waterfall charts
- **Target:** CFO, finance teams
- **Note:** Considerato "il Figma del financial planning", alternativa moderna ad Anaplan

### 2. Causal — causal.app — UX 9.5/10
- **Tipo:** Web, financial modeling + scenario simulation
- **Prezzo:** Acquisito da Lucanet (Oct 2024), era ~$50-200/mese
- **UI:** Spreadsheet turbocharged, variabili invece di celle, grafici bellissimi out-of-the-box
- **Cosa fa:** Monte Carlo integrato, scenario planning con cursori interattivi, cohort modeling
- **Target:** Startup, finance teams
- **Note:** L'unico tool nato con design come priorita'. Futuro incerto post-acquisizione Lucanet

### 3. Runway — runway.com — UX 9/10
- **Tipo:** Web, FP&A + business simulation per startup
- **Prezzo:** Startup pricing
- **UI:** Moderna, AI Copilot genera scenari da prompt naturale
- **Cosa fa:** Cambi hiring/prezzi/spesa → vedi effetto su runway, cash, margini in real-time
- **Target:** Team finance + non-finance
- **Note:** Report interattivi sempre aggiornati, live data integration

### 4. Machinations.io — machinations.io — UX 9/10
- **Tipo:** Web, game economy + system flow simulation
- **Prezzo:** Free → paid
- **UI:** Unica — diagrammi interattivi animati, flussi di risorse visibili in real-time
- **Cosa fa:** "Digital twins" di economie, 1-click Monte Carlo, 2,500+ game studios
- **Target:** Game designers, ma applicabile a tokenomics, business process, risk
- **Note:** **IL PIU' VICINO al nostro concept** — ma per game economy, non vita reale

## Tier A — Moderno e usabile

### 5. Loopy — ncase.me/loopy — UX 8.5/10
- **Tipo:** Web, open source, GRATIS
- **UI:** Minimalista, quasi artistico. Canvas bianco, cerchi e frecce animati
- **Cosa fa:** Causal loops animati, feedback loops con propagazione visiva
- **Target:** Educatori, policy makers, chiunque
- **Note:** Opera di Nicky Case (vincitore Games for Change). Limitato a causal loops

### 6. Kumu — kumu.io — UX 8.5/10
- **Tipo:** Web, $9/mese (gratis per pubblico)
- **UI:** Decorazioni data-driven (colore, dimensione, spessore guidato dai dati)
- **Cosa fa:** Systems mapping, network visualization, "unfold step-by-step" presentations
- **Target:** UNDP, ricercatori, policy makers
- **Note:** Community detection automatica, export, filtering/focus

### 7. FlexSim (Autodesk) — flexsim.com — UX 8/10
- **Tipo:** Desktop (Win/Mac), $5-20K/anno
- **UI:** 3D cinematografico, dark mode (2025), shadows & lighting
- **Cosa fa:** Simulazione 3D drag-and-drop (magazzini, fabbriche, ospedali)
- **Target:** Engineers, operations, manufacturing
- **Note:** Acquisito da Autodesk. Il piu' WOW per demo a stakeholder

### 8. Simul8 — simul8.com — UX 7/10
- **Tipo:** Desktop + Web, $6,049/anno
- **UI:** Moderna, ribbon toolbar, icone flat design
- **Cosa fa:** Drag-and-drop flowchart 2D con icone animate durante simulazione
- **Target:** Business analysts, consultants
- **Note:** "Easier to use than Arena" (Capterra). Ha Decision Cloud per stakeholder

### 9. Vizzu — vizzuhq.com — UX 9/10 (output)
- **Tipo:** Web, data storytelling animato
- **UI:** Transizioni cinematografiche tra stati dei dati
- **Cosa fa:** Trasforma dati in presentazioni animate — perfetto per "come evolve un sistema"
- **Note:** Piu' data viz che simulazione, ma output visivo impressionante

- **Cosa fa:** Gold standard accademico per system dynamics

## Il nostro gap di mercato

```
ESISTE                              NON ESISTE (il nostro spazio)
─────────────────────────────────   ────────────────────────────────────
Pigment/Causal = numeri finanziari  Input naturale → flow visuale
Machinations = game economy         Scenari di VITA REALE
Loopy = causal loops astratti       Persone animate + dati consulting
AnyLogic = enterprise pesante       Consumer-friendly, zero learning curve
QuickSim = albero AI (2 stelle)     Flowchart animato + probabilita' reali
```

**La combinazione vincente che nessuno ha:**
1. Input in linguaggio naturale ("voglio aprire un cafe in Indonesia")
2. AI genera flowchart completo (desiderio → azione → bottleneck → outcome)
3. Probabilita' reali da dati consulting (McKinsey, CB Insights, etc.)
4. Simulazione animata visuale (persone che camminano nel flusso)
5. Output: "il tuo scenario ha 12% di successo, ecco dove muoiono tutti"

## Stack consigliato

| Componente | Opzione | Note |
|------------|---------|------|
| **Frontend** | React + xyflow (React Flow) | 36K stelle, standard, o vanilla JS per MVP |
| **AI generation** | Claude API / GPT | Genera nodi+edge+probabilita' da input |
| **Dati probabilita'** | CB Insights, Startup Genome, McKinsey reports | Pre-caricati come template |
| **Animazione** | SVG persons + CSS transitions | Gia' implementato nel nostro MVP |
| **Backend** | FastAPI | Per proxy API calls |
| **Deploy** | Vercel (frontend) + Fly.io (backend) | Stack gia' usato in Cafepedia |
