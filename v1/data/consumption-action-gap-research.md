## 6. Key Ratios and Meta-Patterns

### The Consumption-Action Funnel

| Stage | Ratio | Example |
|-------|-------|---------|
| Content seen | 100% | Feed impression |
| Content engaged (like/comment/share) | 0.5–4% | Platform analytics |
| Content shared but not read | 59% of shares | Columbia study |
| Courses bought → started | ~30% | Udemy data |
| Courses started → completed | 5–15% | MOOC data |
| Emails received → clicked | ~2% | MailerLite |
| Apps downloaded → used after 30 days | 5–10% | App analytics |
| Resolutions made → kept | ~9% | Survey data |
| Cart items → purchased | ~30% | Inverse of 70% abandonment |
| Job applications → completed | ~10% | Appcast/recruiter data |
| Articles in "read later" → actually read | Estimated <10% | Anecdotal/Pocket behavior |

### The "Consume-Not-Act" Paradox Numbers

| Behavior | The Visible Number | The Hidden Number |
|----------|--------------------|-------------------|
| Social media followers | Millions | 0.029% actually engage (Twitter) |
| Books bought | Record sales | Reading hours at 30-year low |
| Courses sold | Billions in revenue | 70% never opened |
| Newsletter subscriptions | High list sizes | 98% don't act |
| Apps installed | 80/phone | 62% unused monthly |
| Bookmarks saved | Thousands | Most never reopened |
| NY resolutions set | ~45% of adults | 91% fail |
| Screenshots taken | Billions daily | Most never reviewed |
