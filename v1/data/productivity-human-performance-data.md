### Deliberate Practice vs. Ordinary Practice

| Data Point | Value |
|---|---|
| Definition of deliberate practice | Focused, goal-oriented practice with immediate feedback and adjustment |
| Key element missing from ordinary practice | Feedback loop and progressive challenge |
| Improvement from mechanical repetition alone | Minimal or plateaus |
| Ideal session length for deliberate practice | 60-90 min (elite performers rarely exceed 4h/day) |
| Hours/day elite musicians practice deliberately | 3-4 hours (not 8+) |
| Role of a coach/feedback source | Critical — cannot be replaced by volume alone |

### Learning Curves

| Curve Type | Description | Example Skills |
|---|---|---|
| S-Curve (Sigmoid) | Slow start → rapid growth → plateau | Most complex skills |
| Diminishing Returns | Fast early gains → slower later | Simple procedural tasks |
| Increasing Returns | Slow start → accelerating gains | Skills requiring prerequisite knowledge |
| Power Law of Learning | Performance improves as a power function of practice trials | Universal across domains (Newell & Rosenbloom 1981) |

### Key Modifiers of Skill Acquisition Speed

| Factor | Impact |
|---|---|
| Age of start | Earlier = faster neural encoding in many domains |
| Immediate feedback | Multiplier on practice quality |
| Working memory capacity | Correlates with learning speed |
| Prior related knowledge | Transfer effects reduce time to proficiency |
| Genetic predisposition | Significant but not deterministic |
| Sleep (consolidation) | Critical — deprivation eliminates gains from practice |

| Retrieval practice vs reviewing notes | Testing yourself outperforms passive review | Roediger & Karpicke 2006 |
